# أسواق بدر
1. أنشئ مستودعًا جديدًا على GitHub وارفع كل محتويات هذا المجلد (بما فيه .github).
2. من تبويب Actions شغّل Build Aswaq Badr (أو أي push على main).
3. بعد انتهاء البناء نزّل من Artifacts: AswaqBadr-Windows-EXE (ملف التثبيت) و AswaqBadr-Android-APK.
- نسخة الويندوز بدون كاميرا، وتحفظ المبيعات تلقائيًا في سطح المكتب داخل مجلد Aswaq Badr.
- نسخة الأندرويد: استلام سريع، جرد، استعلام أسعار، استيراد البيانات، وتصدير الملفات عبر قائمة المشاركة.
- التطوير: npm install ثم npm start.
